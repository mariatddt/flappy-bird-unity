# Flappy Bird — Unity

A Flappy Bird-inspired game developed in Unity using C#.

## About

This project recreates the core mechanics of Flappy Bird, including player movement, obstacle avoidance, collision detection and scoring.

## Features

- Player movement and jump mechanics
- Procedurally or repeatedly generated obstacles
- Collision detection
- Score tracking
- Game-over and restart functionality

## Technologies

- Unity
- C#
